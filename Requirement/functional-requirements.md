## 2. 功能解释规则

- 只实现设计索引中的有效页面和支撑这些页面闭环所必需的后台能力。
- `-dep` 页面和原始导出包不产生功能需求。
- 同一业务的错误、成功、等待和弹层截图视为同一页面状态，不实现为互相独立的数据模型。
- `reference.png` 与当前 HTML 冲突时，以当前 HTML 的字段和操作为准；参考图只约束布局与视觉层级。
- 状态页背景中出现但当前有效主页面没有的菜单、统计和角色文案，不新增为功能。
- 本文中的“功能实现”描述状态、触发、数据和验收行为；具体语言、框架、表结构和接口在技术需求中确定。

## 4. 核心用户流程

### 4.1 新成员进入

1. 用户打开 App，进入登录页。
2. 用户进入注册页，输入手机号、密码和确认密码。
3. 系统完成本地校验并提交注册。
4. 注册成功后进入待审核页，普通业务入口不可用。
5. 审核管理员在 Web 管理端通过申请。
6. 待审核页轮询、用户手动刷新、App 回到前台或重新登录时发现审核已通过。
8. 用户登录前勾选服务协议和隐私政策。
9. 首次进入主功能时展示相册权限说明并请求完整权限。

### 4.2 首次自动备份

1. 自动备份配置初始值为关闭，移动网络备份初始值为关闭。
2. 未取得完整相册权限时不读取媒体、不建任务。
3. 用户授予完整权限后直接进入正常页面，不显示成功中间页。
4. 数据核心可以分页建立本地浏览索引，但不创建上传任务。
5. 用户主动开启自动备份或点击“开始备份”后，客户端才发现待备份媒体、计算账号内去重指纹并生成备份资源。
6. 满足 Wi-Fi 条件后上传媒体资源。
7. 服务端核对对象完整性后，媒体进入私人空间。
8. 后续相册变化触发增量补扫，重复扫描不会重复创建云端媒体。

### 4.3 私人媒体共享

1. 用户从私人空间打开一条备份完成且未删除的媒体。
2. 用户点击“共享到家庭相册”。
3. 客户端提交共享请求，服务端验证所有权并更新家庭可见性。
4. 服务端事务性写入共享状态后返回成功。
5. 媒体出现在家庭相册；私人详情切换为已共享状态。
6. 用户取消共享时进行一次确认；成功后立即停止后续家庭访问授权。

### 4.4 删除与恢复

1. 所有者在私人详情选择移入回收站。
2. 确认弹层说明云端可见性变化和设备本地媒体不受影响。
3. 服务端记录首次 `trashed_at`，媒体从私人空间和家庭相册隐藏。
4. 用户从个人中心进入回收站。
5. 用户确认恢复后，媒体回到私人空间并保持未共享。
6. 永久清理由隔离运维工具执行，App 和在线 API 不提供永久删除。

## 5. F-01 注册、登录、协议与会话

### 5.1 功能要求

- 注册字段固定为手机号、密码、确认密码。
- 手机号仅接受中国大陆 11 位移动号码；客户端显示原始输入，提交前标准化为 `+86` E.164。
- 密码长度为 8～64 个字符，至少包含字母和数字；允许常见可输入符号，不强制特殊符号。
- 客户端校验必填、手机号格式、密码规则和两次密码一致性；服务端重复校验。
- 手机号已存在时返回稳定错误，不重复创建账号。
- 注册成功后账号状态为 `PENDING`。
- 登录字段固定为手机号和密码。
- 每次登录前必须勾选服务协议和隐私政策；协议勾选是登录请求的客户端前置条件，服务端记录本次接受的协议版本。
- 登录结果区分：凭据错误、待审核、网络不可用、服务不可用和成功。
- 不通过错误文案区分“账号不存在”和“密码错误”，统一为“手机号或密码错误”。
- App 启动时恢复会话；Access Token 失效但 Refresh Token 有效时静默刷新。
- 会话彻底失效时停止当前账号任务、清理凭据和内存密钥并进入登录页。
- 主动退出前展示确认；退出后撤销当前设备会话。
- 同一设备切换账号必须先退出当前账号。

### 5.2 页面状态

```text
LoginIdle
LoginValidating
LoginSubmitting
CredentialError
NetworkError
ServiceError
RegistrationEditing
RegistrationValidationError
RegistrationSubmitting
RegistrationFailed
PendingApproval
ApprovalRefreshing
Approved
SessionRestoring
SessionExpired
```

`SessionExpired` 是内部状态，只触发跳转，不展示独立页面。

### 5.3 功能实现

- 登录和注册按钮在提交期间禁用，避免重复请求。
- 协议链接打开内置文档页；返回后保留输入和勾选状态。
- 待审核页可见时每 10 秒查询一次，连续失败使用 10、20、40、60 秒上限退避；用户主动刷新不受轮询节奏限制。
- App 回到前台时立即查询一次审核状态。
- 退出和会话失效先停止任务调度，再清除凭据；后台回调即使晚到也不得恢复已退出账号的页面状态。

### 5.4 验收

- 未勾选协议不会发出登录请求。
- 重复点击注册只产生一个待审核账号。
- `PENDING` 账号不能访问普通成员 API。
- 会话失效不会停留在备份页或显示独立过期页。
- 退出后旧 Access/Refresh Token 均不能继续建立有效会话。

## 6. F-02 注册审核

### 6.1 功能要求

- Web 管理端使用独立管理员登录。
- 首次管理员由部署时的一次性初始化命令创建；MVP 不在页面中创建或管理管理员。
- 待审核列表展示脱敏手机号、注册时间和申请状态。
- 管理员可以查看申请详情并执行“通过”。
- 通过操作必须二次确认并防止重复提交。
- 审核成功记录操作者、目标账号、时间和请求追踪 ID。
- 管理端不提供拒绝、停用、删除、重置密码、修改资料或查看媒体能力。

### 6.2 功能实现

- 账号状态只允许 `PENDING -> APPROVED`，没有反向流转。
- 并发审核使用数据库条件更新；第二个请求读取最新状态并返回幂等成功。
- 列表采用游标分页，默认按注册时间从旧到新，便于先处理等待最久的申请。
- 管理端会话 30 分钟无操作失效；敏感操作要求有效的服务端 Session Cookie 和 CSRF 防护。

### 6.3 验收

- 普通家庭成员凭据不能登录管理端。
- 管理端 API 无法获得媒体列表或对象地址。
- 同一申请最多发生一次有效状态转换，但重复请求不产生错误副作用。

## 7. F-03 个人资料与个人中心

### 7.1 功能要求

- 展示头像、昵称和脱敏手机号。
- 默认昵称为手机号后四位。
- 昵称去除首尾空白后为 2～20 个字符，允许中文、字母、数字、空格、连字符和下划线。
- 头像支持 JPEG、PNG、HEIC/HEIF 和 WebP；原始选择文件最大 10 MiB。
- 客户端裁剪为正方形，生成不超过 1024×1024 的展示头像后上传。
- 编辑昵称和头像分别保存；失败时保留当前编辑内容并允许重试。
- 个人中心的“备份设置”“回收站”“我分享的”“帮助与反馈”必须到达对应功能。
- 完整手机号只在本人登录输入场景使用，家庭相册只显示昵称和头像。

### 7.2 功能实现

- 头像是个人资料资源，不与媒体备份、私人空间或家庭相册资源混用。
- 昵称或头像修改成功后，使本人个人中心和后续家庭相册列表读取到新版本。
- 已加载的旧家庭列表可以在下次刷新或重新进入时更新，不要求推送实时刷新。

### 7.3 验收

- 用户不能修改手机号、账号状态或角色。
- 任意其他成员页面和管理端审核列表都不显示完整手机号。
- 所有个人中心入口均有有效目标，不保留 `#` 占位跳转。

## 8. F-04 相册权限

### 8.1 功能要求

- 首次扫描前展示统一权限说明页。
- 页面提供“继续授权”和“暂不开启”。
- 顶部媒体区域保持高斯模糊，不能使用真实可读本地内容冒充已授权状态。
- 权限语义分为：未决定、完整授权、部分授权、受限、拒绝、系统限制。
- 除完整授权外，其余状态统一留在权限说明页。
- 完整授权后直接进入私人空间，并在后台启动扫描；不显示授权完成页。
- 系统设置修改权限后，App 回前台立即复查。

### 8.2 功能实现

- “继续授权”优先发起系统授权；已经拒绝且系统不再弹窗时跳转 App 设置页。
- “暂不开启”停留在无备份能力的正常受限状态；下次进入备份入口仍展示统一权限页。
- 权限从完整降级后立即停止新扫描和新上传调度，保留已确认完成结果和可恢复任务记录。
- 部分授权内容不进入备份，避免页面声称已完整保护相册。

### 8.3 验收

- 任何非完整权限状态都不会创建扫描或上传任务。
- 完整权限后没有成功中间页。
- 权限撤销后后台任务不会继续读取新的本地媒体。

## 9. F-05 自动备份设置

### 9.1 功能要求

- 自动备份首次默认关闭。
- 允许移动网络备份首次默认关闭。
- 设置页只显示这两个开关。
- 关闭自动备份时，移动网络开关禁用但保留其上次值。
- 重新开启后恢复上次移动网络选择。
- 本地相册关闭状态显示“开始备份”按钮；点击等价于开启自动备份。

### 9.2 功能实现

- 自动备份设置属于账号加设备配置；同一账号在不同设备分别控制。
- 配置变化先写入本地持久状态，再更新任务调度；服务端只接收必要的任务结果，不把 UI 开关作为全局账号配置。
- 关闭时停止创建新任务并请求平台停止尚未开始或可安全暂停的任务；已经被 OSS 确认完成的上传不得回滚。
- 移动网络开关变化立即更新等待任务的网络约束。

### 9.3 验收

- 全新安装且完成登录后，自动备份为关、移动网络为关。
- 关闭后不会发现待备份媒体或上传新媒体，但不影响用户刷新和浏览本地索引。
- “开始备份”不会建立第二套配置逻辑。

## 10. F-06 设备媒体扫描与本地相册

### 10.1 功能要求

- 完整扫描覆盖全部可访问历史媒体。
- 增量扫描覆盖新增、修改、删除和相册归属变化。
- 支持照片、视频、GIF、实况照片以及平台明确支持的动态媒体。
- 记录平台本地标识、媒体类型、格式、尺寸、时长、拍摄时间、修改时间和一个或多个相册归属。
- 不读取、展示、搜索或单独上传 GPS 位置字段。
- 本地相册页面按设备相册文件夹分区，每区三列网格。
- 总览媒体按拍摄时间从新到旧；同一媒体在总览只出现一次，在对应相册中分别出现。

### 10.2 已确认行为

- 设备相册改名：保留稳定平台相册标识，下次扫描同步新名称。
- 相册归属变化：更新关系，不复制媒体。
- 媒体内容被编辑：内容指纹变化时作为一个新版本/新媒体备份，不覆盖已保存原文件。
- 设备本地删除：只标记本地条目不可用，不删除云端媒体。
- 系统云相册资源未下载：进入“等待本地资源”状态，不误报完成。
- 大相册分页读取，每批最多 500 条描述记录，实际批量可按平台性能下调。

### 10.3 功能实现

- 扫描使用可恢复游标；每批结果事务性写入本地索引。
- 系统变化通知只触发核对，不直接修改最终业务状态。
- 缩略图请求与可见区域绑定，离开屏幕后取消无用请求。
- 本地相册页面可浏览本地媒体，但点击本地媒体不产生云端删除或共享操作。

### 10.4 验收

- 10 万条媒体规模下扫描可以分批完成，App 不因一次加载全部描述而失去响应。
- 重复全量扫描不会重复创建同一设备条目的待上传任务。
- 一条媒体属于多个相册时，云端资源只保存一份对象资源集合。

## 11. F-07 媒体传输安全与完整性

### 11.1 功能要求

- 原文件、缩略图、视频封面和预览不执行客户端应用层加密。
- App、ECS API 和 OSS 之间只允许使用校验证书的 HTTPS/TLS。
- OSS Bucket 保持私有，客户端只能取得短期、限账号、限对象和限用途的授权。
- 私人媒体只向所有者签发访问授权；家庭共享只增加服务端可见性记录，不复制或重新上传原文件。
- 上传完成和加载完成均校验资源长度与 SHA-256；校验失败的文件不得进入可见列表或系统相册。
- 管理后台不提供媒体列表、预览、下载或对象授权接口。

### 11.2 功能实现

- ECS 在每次对象访问前校验账号、所有权、共享状态、回收站状态和授权用途。
- 上传授权限定对象键、方法、大小、摘要和短有效期；读取授权限定资源与用途。
- App 只在受控临时文件或流中处理媒体，完成、取消、退出和失败后按任务状态清理。
- 对象签名地址、媒体正文和云临时凭据不得进入日志、反馈或普通业务数据库字段。
- 旧 Media Key、envelope 和密文字段仅用于数据库与接口迁移，不参与新客户端流程。

### 11.3 验收

- HTTP、无效证书、过期授权、错误对象键和越权账号均被拒绝。
- 修改对象内容、长度或 SHA-256 后，上传完成或加载校验失败关闭。
- 私人媒体未共享时，其他成员不能取得有效对象授权；管理后台没有媒体访问入口。

## 12. F-08 上传队列、续传、去重与状态

### 12.1 状态模型

```text
DISCOVERED
  -> WAITING_PERMISSION
  -> WAITING_RESOURCE
  -> WAITING_NETWORK
  -> PREPARING
  -> ENCRYPTING
  -> UPLOADING
  -> SERVER_VERIFYING
  -> COMPLETED

任意可执行阶段 -> RETRYABLE_FAILED -> 对应等待/执行阶段
任意可执行阶段 -> PERMANENT_FAILED
自动备份关闭   -> PAUSED_BY_SETTING
```

### 12.2 功能要求

- 队列和进度必须持久化，App 重启、设备重启和版本升级后可核对恢复。
- 初次扫描按拍摄时间从新到旧创建任务，使近期内容优先出现在私人空间。
- 用户不操作单条任务；MVP 不提供单任务暂停、取消或忽略。
- 可重试失败自动有限重试，并在页面提供“重试”。
- 永久失败停止自动重试，只提供用户主动重试；不提供“忽略”。
- 上传中展示当前媒体和当前资源百分比。
- “同步完成”表示当前设备所有符合权限和网络条件的任务都已由服务端确认完成。

### 12.3 去重

- 同设备条目标识和版本用于快速本地去重。
- 对原始资源计算账号私有的键控内容指纹，用于同账号跨设备和重复下载去重；服务端不能据此比较不同账号的相同内容。
- 创建上传会话、完成分片、完成媒体记录都必须幂等。
- MineG 保存回系统相册时记录本地下载回执；扫描优先用回执识别，其次用账号键控内容指纹兜底。

### 12.4 异常展示

- 等待 Wi-Fi：连接符合条件的网络后继续。
- 网络离线：网络恢复后从已确认进度继续。
- 设备空间不足：提示释放设备空间后重试。
- 云端或服务空间不足：停止新上传，提示稍后重试或联系管理员，不要求用户在 App 内清理配额。
- 服务不可用：保留本地媒体浏览，采用退避自动重试。
- 登录失效：离开备份页并进入登录流程。

### 12.5 验收

- 分片重试不重新传输已确认分片。
- 服务端未确认前不得显示完成。
- 同账号并发上传相同内容最终只产生一个有效媒体记录。
- 不同成员上传相同内容仍保留各自独立、不可互相推断的媒体记录。

## 13. F-09 私人空间与媒体详情

### 13.1 功能要求

- 只查询当前用户拥有、备份完成且未删除的媒体。
- 总览三列网格按拍摄时间从新到旧，使用游标加载。
- 支持加载中、空状态、有数据、首次加载失败和继续加载失败。
- 网格使用完成长度与 SHA-256 校验的缩略图；缩略图缺失时显示中性占位并允许重试。
- 照片全屏显示；GIF 动态显示；视频支持播放、暂停、拖动和停止；实况照片优先使用平台原生展示。
- 详情展示媒体标题或默认名称、拍摄时间、媒体类型、时长或文件大小等基础信息；不展示 GPS 位置。
- 操作栏提供下载、共享或取消共享、移入回收站和展开/收起。
- 不提供搜索、筛选、收藏、编辑拍摄地点或编辑文件内容。

### 13.2 兼容与降级

- 首批保证 JPEG、PNG、HEIF/HEIC、GIF、MP4、MOV、H.264、HEVC 和各平台实况/动态照片组合。
- 平台不能原生展示的格式优先生成客户端预览；无法安全预览时显示文件类型占位，但保留私人原文件保存能力。
- 预览失败不改变原文件完成状态。

### 13.3 验收

- 不能通过修改 ID 查看其他成员未共享媒体。
- 详情短期授权过期时自动重新鉴权，不保存永久对象地址。
- 大列表不会一次性加载所有媒体或原文件。

## 14. F-10 私人原文件保存

### 14.1 功能要求

- 入口只存在于所有者的私人媒体详情。
- 下载前验证所有权并取得短期对象访问授权。
- 下载过程中显示百分比。
- 客户端验证完整资源的长度与 SHA-256 后写入设备系统相册。
- 只有系统相册写入成功后显示“已成功保存到系统相册”。
- 网络、授权、完整性校验、系统权限和设备空间错误分别归类；失败可重试或取消。
- 不调用系统分享面板，不提供文件位置选择器。

### 14.2 重复保存决定

- 本机存在 MineG 下载回执且目标媒体仍可访问时，直接提示已保存，不重复写入。
- 回执丢失或系统相册条目被用户删除时，允许再次保存。
- 新写入条目携带本地回执，以便备份扫描排除重复。

### 14.3 验收

- 家庭相册没有任何原文件保存入口或授权接口。
- 完整性校验失败的文件不会写入系统相册。
- 实况照片等多资源媒体按完整资源集合保存。

## 15. F-11 单媒体共享与取消共享

### 15.1 功能要求

- 只有所有者可以共享或取消共享。
- 只有备份完成且未删除的媒体可以共享。
- 一次只操作一条媒体。
- 首次共享不弹二次确认，成功后显示“共享成功”。
- 已共享详情显示共享状态并将主操作改为“取消家庭共享”。
- 取消共享必须二次确认。
- 重复共享和重复取消共享保持幂等。
- 删除媒体时自动取消其家庭可见性。

### 15.2 功能实现

- 共享请求事务性更新媒体家庭可见性；写入失败不显示成功。
- 取消共享后服务端拒绝新的列表、详情、预览和播放授权。
- 已签发的短期地址必须受短有效期、对象与用途范围限制；客户端在下次授权失败后退出详情。
- 取消共享不删除私人媒体、不改变所有权、不删除原文件。

### 15.3 验收

- 非所有者无法改变共享状态。
- 共享失败时保留服务端最后确认的状态。
- 删除或取消共享后，新的家庭列表查询立即不返回该媒体。

## 16. F-12 家庭相册浏览

### 16.1 功能要求

- 只返回仍共享且未删除的媒体。
- 时间线按拍摄时间从新到旧，并按本地时区的今天、昨天或日期分组。
- 首页“共享”Tab 查询全部家庭共享媒体；个人中心“我分享的”入口只查询所有者为当前用户的共享媒体。
- 两个列表使用独立页面状态和游标，进入页面时均从第一页查询。
- 卡片展示媒体类型、时长以及共享者昵称和头像。
- 详情展示共享者和拍摄日期。
- 支持照片、GIF、视频和实况照片的只读查看。
- 不显示分享时间，不提供下载、保存、导出、系统分享、点赞或评论。

### 16.2 功能实现

- `all` / `mine` 查询条件在服务端鉴权和分页之前应用。
- 家庭详情使用独立的只读短期授权，不能转换为私人下载授权。
- 共享者资料变化后，下一次加载显示最新昵称和头像。
- 正在查看的媒体被取消共享或删除后，下一次授权请求失败并退出详情。

### 16.3 验收

- 个人中心“我分享的”结果不混入其他成员媒体。
- 家庭接口无法获得原文件下载权限。
- 未共享和已删除媒体不能通过直接请求访问。

## 17. F-13 逻辑回收站与恢复

### 17.1 功能要求

- 删除确认必须说明媒体会从私人空间和家庭相册隐藏、不会删除设备本地媒体、人工清理前可以恢复。
- 删除只改变服务端业务状态，不移动或复制 OSS 对象。
- 首次删除记录不可变的 `trashed_at`；重复请求不得刷新该时间。
- 回收站只展示当前用户媒体，按 `trashed_at` 从新到旧。
- 卡片显示“已删除 N 天前”等已放置时长，不显示自动到期日。
- 回收站从个人中心进入，顶部返回个人中心。
- 恢复前确认；恢复后回到私人空间且保持未共享。
- App 无永久删除按钮。

### 17.2 人工永久清理

- 使用受限 CLI 工具，不加入移动端或首版审核后台页面。
- 工具先生成 JSON 清单，包含筛选条件、媒体数、对象数、总容量和对象摘要。
- 清单保存到受限审计位置并记录 SHA-256；操作者再次输入清单 ID 才能执行。
- 执行前重新核对媒体仍处于回收站，已恢复媒体必须跳过。
- 逐对象记录成功或失败；只有完整资源集合清理成功后才写 `purged_at`。
- 清理审计记录至少保留 3 年。

### 17.3 验收

- 在线服务身份没有 OSS 永久删除权限。
- 重复删除不改变 `trashed_at`。
- 恢复后不会自动出现在家庭相册。
- 清单生成后恢复的媒体不会被误删。

## 18. F-14 帮助与反馈

### 18.1 功能要求

- 个人中心入口打开内置帮助页面。
- 帮助页面首批覆盖：相册权限、自动备份、移动网络、媒体隐私与传输安全、家庭共享、回收站和退出登录。
- 反馈表单字段：问题分类、1～1000 字描述、可选联系方式。
- 问题分类固定为：账号、权限、备份、浏览/播放、共享、回收站、其他。
- 不允许附加照片、视频或日志文件。
- 提交成功显示反馈编号；失败保留输入并可重试。

### 18.2 功能实现

- FAQ 内容随 App 发布，首版不建设内容管理系统。
- 反馈写入后端数据库，管理后台首版不提供处理界面；由受限运维查询导出。
- 自动附加 App 版本、平台、系统版本和匿名设备安装标识；不附加令牌、密钥、对象地址或完整手机号。

### 18.3 验收

- 无网络时 FAQ 仍可查看。
- 反馈重复点击只创建一条记录。
- 反馈数据不包含媒体内容、对象签名地址或云临时凭据。

## 19. 跨功能规则

### 19.1 列表与时间

- 服务端时间使用 UTC，客户端按设备时区展示。
- 私人空间和家庭相册按媒体拍摄时间倒序。
- 回收站按首次删除时间倒序。
- 列表接口使用游标分页；切换过滤条件不得复用旧游标。

### 19.2 幂等

注册、审核、上传会话创建、分片确认、媒体完成、分享、取消分享、删除、恢复、资料更新和反馈提交都必须定义幂等行为。

### 19.3 安全

- 客户端隐藏按钮不能替代服务端授权。
- 日志、错误、反馈和管理端不记录完整令牌、STS 凭据、对象签名地址或媒体正文。
- 短期对象地址不能成为永久访问凭据。
- 传输证书、对象授权或媒体完整性校验失败时采取失败关闭策略，不上传或展示未验证媒体。

### 19.4 空状态与错误

每个列表至少覆盖首次加载、空数据、成功有数据、首次失败和继续加载失败。任何可重试操作在重试期间都必须防止重复点击。

## 21. 功能完成定义

一个功能只有同时满足以下条件才算完成：

1. 对应有效设计状态均可由真实数据驱动，不是静态假数据。
2. 正常、空、等待、错误、重试和权限失效路径均有测试。
3. 服务端授权、对象可见性和客户端按钮可见性三者一致。
4. App 重启、网络切换、进程回收和重复请求后状态仍正确。
5. Android 功能实现前已登记关键方法、数据桥接和 UI 交互契约，通过后冻结；iOS 和 HarmonyOS 后续由同一契约测试验证。
6. 没有遗留 `#` 跳转、模拟成功、仅内存任务状态或设计中已废弃的页面入口。
