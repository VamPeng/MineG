# MineG 私人家庭相册 App 产品需求

> 当前范围提示（2026-07-30）：业务服务统一部署在公网 ECS，媒体保存在私有阿里云 OSS；上传、预览和原文件加载不做客户端应用层媒体加密，传输统一使用 HTTPS/TLS。旧“媒体端到端加密”文案和字段只作为兼容迁移输入，不得用于新页面或新功能。

## 1. 文档信息

- 项目名称：MineG
- 文档版本：v2.1
- 文档状态：设计对齐后的 MVP 产品基线
- 核定日期：2026-07-26
- 产品目标：为本人和对象两名固定用户提供自动备份、个人私密保存和双人共享浏览能力。
- 设计基线：[MineG Stitch 移动端原型](./Prototype/Stitch/README.md)
- 功能基线：[MineG MVP 功能需求](./functional-requirements.md)
- 技术基线：[MineG 技术需求](./technical-requirements.md)

### 1.1 本次核定结论

本版以当前有效设计为产品行为基线，替代 v1.3 中与设计不一致的结论。主要变更如下：

- 自动备份改为默认关闭；完整相册权限只允许建立本地浏览索引，用户主动开启自动备份后才开始发现待备份媒体并上传。
- 登录页每次提交前都必须勾选服务协议和隐私政策。
- 相册权限的异常状态统一使用一个授权说明页；完整授权后直接进入正常页面，不展示授权成功中间页。
- 固定三项底部主导航：首页、备份、我的；首页图标沿用私人空间 Icon，仅显示 Icon。
- 首页顶部使用“私人 / 共享”双 Tab，分别展示原私人空间和家庭相册内容。
- 私人媒体详情保留下载、共享或取消共享、移入回收站操作。
- 共享 Tab 展示全部家庭共享媒体，不提供下载、保存、导出或二次分享；“我分享的”从个人中心进入独立列表。
- 回收站只从个人中心进入；恢复后保持私有，不恢复原家庭共享状态。
- 个人中心保留昵称、头像、脱敏手机号、备份设置、回收站、我分享的、帮助与反馈和退出登录。
- 媒体上传和加载不做客户端应用层加密；通过 HTTPS/TLS、私有 OSS、短期对象授权、业务权限和审计保护媒体。
- 原 `-dep` 页面、原始压缩包中的授权成功页以及废弃决策不进入 MVP。

## 2. 设计优先级与解释规则

当前页面资料以 HTML 原型为唯一内容基线。发生差异时按以下顺序解释：

1. `Prototype/Stitch/README.md` 中的有效页面清单、已采用决策和废弃标记。
2. 有效页面当前 `index.html` 的可见内容、状态和交互。
3. `THEME.md` 是颜色、导航 Icon 和视觉 Token 的唯一正式基线。
4. `source-archives/` 与任何 `-dep` 页面只用于追溯，不生成产品需求。

原页面参考 PNG 已删除，不得从历史截图恢复字段、操作、布局或文案。

状态页只补充该页面名称所表达的状态。例如“保存成功”“退出确认”页面的背景内容不自动增加新的菜单、角色、统计或编辑能力。

## 3. 产品原则

### 3.1 核心价值

- 自动备份设备相册中的家庭照片、视频、GIF 和实况照片，降低原始媒体丢失风险。
- 每位成员拥有默认私密、相互隔离的私人空间。
- 成员可以主动把单张私人媒体共享给固定家庭中的其他成员浏览。
- 私人下载、家庭只读、逻辑删除和人工永久清理具有清晰边界。
- 媒体对象保存在私有 OSS；服务端和管理后台按最小权限设计，管理端产品不提供媒体浏览能力。

### 3.2 产品边界

- 系统只服务本人和对象两名固定用户。
- 不支持创建、加入或切换多个家庭。
- 当前不做推广、增长、获客、成员扩张或面向陌生用户的产品信任建设。
- MVP 优先保证备份可靠性、媒体质量、权限隔离和恢复能力。
- 设备本地媒体和云端媒体相互独立；任何一端的删除不自动删除另一端。
- 设计中没有页面或入口、且不是支撑现有流程所必需的业务能力，不进入 MVP。

### 3.3 UI 内容最小化

- UI 只展示完成当前 MVP 交互所需的操作、输入、真实状态、阻塞原因和直接后果。
- 删除后不影响用户下一步操作、当前状态判断或直接后果理解的元素，一律不展示。
- “私人云”“加密”“存储”“安全”“隐私保护”等不参与当前交互的提示、徽章、卡片、页脚、图标和宣传文案全部移除。
- 不展示云端照片总数、关联成员数、加入天数、容量套餐等没有对应 MVP 操作的数据。
- 不提供品牌口号、产品承诺、推广文案、信任背书或仅用于填充留白的说明。
- 相册授权用途、任务进度、失败原因、空间不足、流量费用、协议确认、删除/恢复/退出后果等会影响操作的信息必须保留，并只描述当前事实和下一步。
- 全量 HTML 原型的具体清理范围与验收方法以 [MVP UI 内容约束与原型清理规则](./Prototype/Stitch/UI-CONTENT-RULES.md) 为准。

## 4. 用户与角色

| 角色 | 使用端 | 权限 |
| --- | --- | --- |
| 访客 | 移动端 | 注册、登录、查看协议 |
| 待审核成员 | 移动端 | 查看审核状态、刷新状态、重新登录、退出 |
| 已审核成员 | 移动端 | 管理本人资料、备份、私人媒体、家庭共享和本人回收站 |
| 审核管理员 | Web 管理端 | 登录、查看待审核申请、通过申请 |
| 运维清理人员 | 独立运维工具 | 预览并人工永久清理回收站对象 |

- 审核管理员和运维清理人员不能通过管理产品能力查看或下载家庭媒体；拥有 ECS/OSS 高权限的运维身份在技术上可能读取未做客户端加密的对象，必须受最小权限、审批和审计约束。
- 移动端不提供成员管理、角色管理、账号停用或账号删除入口。
- 设计中的“家庭管理员”面向用户表示负责另一名固定用户准入审核的人；实现上由独立 Web 管理端完成。

## 5. 信息架构与主导航

登录成功且审核通过后，App 使用三项底部主导航：

1. 首页：通过顶部“私人 / 共享”双 Tab 切换当前成员自己的云端媒体和全家当前仍处于共享状态的媒体。
2. 备份：设备本地相册和同步状态。
3. 我的：个人资料和功能入口。

导航要求：

- 只显示三个 Icon，不显示可见文字；必须提供无障碍名称。
- 回收站不占用主导航，只能从“我的”进入。
- 媒体详情、备份设置、回收站和退出确认使用次级页面或弹层，并提供明确返回路径。

## 6. 注册、登录与审核

### 6.1 注册

- 用户使用中国大陆手机号、密码和确认密码注册。
- 不使用短信验证码。
- 提交前检查必填、手机号格式、密码规则和两次密码一致性。
- 手机号已注册、手机号无效、密码不一致、网络失败和服务失败分别给出明确反馈。
- 注册成功后账号进入“待审核”，不能进入私人空间、家庭相册或备份页面。

### 6.2 审核

- 审核由独立 Web 管理端人工完成。
- 待审核页展示“正在同步”或“待审核”状态，并提供刷新状态、重新登录和退出当前账号操作。
- 页面可在可见期间低频刷新；用户也可以主动刷新。
- 审核通过后，用户下一次刷新、回到前台或重新登录时进入 App；准入不依赖其他成员设备在线或密钥授权，不新增中间页面。

### 6.3 登录与协议

- 登录使用手机号和密码。
- 每次登录前，用户必须主动勾选“我已阅读并同意服务协议与隐私政策”。
- 未勾选时不得发起登录请求。
- 登录错误至少区分凭据错误、网络不可用、服务不可用和待审核状态。
- 不提供忘记密码、修改密码、修改手机号或账号注销入口。

### 6.4 会话与退出

- App 启动时尝试恢复有效会话。
- 会话可刷新时自动刷新，不打断用户。
- 会话失效或刷新失败时，停止当前账号未完成任务、清理凭据并直接跳转登录页，不展示“登录状态过期”中间页。
- 用户主动退出前展示确认弹层；确认后停止当前账号未完成的备份任务并清理本机凭据。

## 7. 个人资料与个人中心

- 个人中心展示头像、昵称和脱敏手机号。
- 注册成功时默认昵称为手机号后四位。
- 用户可以修改自己的昵称和头像。
- 个人中心提供以下入口：
  - 备份设置；
  - 回收站；
  - 我分享的，进入本人已共享媒体列表；
  - 帮助与反馈；
  - 退出登录。
- “备份设置”入口文案中的同步说明不增加第三个“同步频率”配置；备份设置仍只有两个开关。
- 其他成员只能在家庭相册中看到昵称和头像，不能看到完整手机号。

## 8. 隐私与媒体安全

- 原文件、缩略图、视频封面和预览不执行客户端应用层媒体加密。
- App、ECS API 与 OSS 之间的传输必须使用校验证书的 HTTPS/TLS。
- OSS Bucket 必须保持私有；上传、预览和原文件读取使用短期、限账号、限对象和限用途的授权。
- 私人媒体默认只向所有者签发访问授权；共享媒体只向当前已审核家庭成员签发浏览授权，且不提供家庭原文件保存入口。
- 管理后台不提供媒体列表、预览、下载或对象授权能力。拥有云资源高权限的运维身份在技术上可能读取媒体对象，因此必须执行最小权限、审批、审计和日志脱敏。
- 对象存储服务端加密可以作为云端静态数据保护，但不得被描述为客户端端到端加密。
- 缩略图、视频封面和预览优先由客户端生成；如后续引入服务端处理，必须单独核定访问权限、临时文件和删除规则。
- 取消共享或删除后，服务端立即停止后续授权；已在其他成员设备上显示或缓存过的内容不能承诺绝对收回。
- 产品不承诺阻止系统截屏、录屏或用户在获得显示权限后提取画面。

## 9. 相册权限与自动备份

### 9.1 权限流程

- 首次需要读取设备媒体前，先展示统一的权限用途说明，再发起系统授权。
- 未决定、部分授权、访问受限、拒绝或系统限制，均展示同一个权限说明页。
- 权限说明页顶部媒体保持模糊，提供“继续授权”和“暂不开启”。
- 未获得完整相册权限时不扫描、不创建上传任务，也不声称备份已经开启。
- 获得完整授权后直接进入正常页面，不展示“授权完成”中间页。
- App 回到前台时重新检查权限变化。

### 9.2 默认行为

- 自动备份默认关闭。
- 获得完整相册权限后可以建立本地浏览索引，但不会自动创建上传工作。
- 用户开启自动备份或点击“开始备份”后，才按网络条件发现并上传待备份媒体。
- 默认只在 Wi-Fi 下上传。
- 用户可以开启“允许移动网络备份”。
- 用户可以关闭自动备份；关闭后不再创建新的备份发现和上传工作，未完成任务停止调度但保留可恢复状态；本地浏览索引仍可手动刷新。
- 自动备份关闭时，本地相册列表底部显示“开始备份”悬浮按钮；点击后重新开启并恢复任务。

### 9.3 备份设置

备份设置只提供：

1. 自动备份。
2. 允许移动网络备份。

不提供相册选择、同步频率、单任务暂停、任务忽略、存储配额或定时备份设置。

### 9.4 备份内容与相册组织

- 备份完整权限下设备相册中的照片、视频、GIF 和实况照片。
- 首次扫描覆盖已有历史媒体；后续持续发现新媒体和被编辑后的新版本。
- 设备相册文件夹名作为云端相册组织参考。
- 一条媒体属于多个设备相册时保留多个相册归属，但私人空间总览只展示一份媒体。
- 同一账号的重复扫描、重试和跨设备重复内容不得生成重复云端媒体。
- 从 MineG 下载回系统相册的媒体不得被再次备份成重复云端媒体。

### 9.5 备份页面与状态

- 本地相册页面不展示独立顶部栏，页面从上到下为同步状态区和本地相册列表。
- 刷新与设置使用图标按钮，放置在同步状态卡右上角；设置按钮进入备份设置。
- 本地相册总览使用两列相册卡片；每张卡片展示一张相册缩略图，相册名称以半透明圆角标签叠放在缩略图左下角。
- 点击相册卡片进入单相册页面，单相册内使用三列媒体网格。
- 状态区覆盖：扫描中、上传中、等待 Wi-Fi、网络离线、设备空间不足、云端或服务空间不足、服务不可用、同步完成、自动备份关闭。
- 上传中展示当前媒体、进度和简短说明；全部符合条件的任务完成后展示“同步完成”。
- 登录失效不作为备份状态展示，直接执行会话失效流程。

## 10. 原文件与媒体兼容

- 支持系统相册能够提供的常见照片、视频、GIF 和实况照片。
- “原文件”指媒体内容质量无损，不要求上传前后文件字节或全部非必要元数据完全一致。
- 不得降低分辨率、帧率、码率、色彩、HDR、音频或动态资源质量。
- 必须保留正确显示和播放所需的方向、色彩、编解码、时序和资源关联信息。
- 不额外读取、索引、搜索或展示 GPS 位置，也不为位置元数据申请额外权限。
- 列表使用缩略图或预览，不直接下载原文件作为网格图片。

## 11. 私人空间与媒体详情

- 首页顶部固定展示“私人 / 共享”双 Tab，默认选择“私人”。
- 私人空间只展示当前成员拥有、备份完成且未进入回收站的媒体。
- 默认使用三列网格，支持照片、视频、GIF 和实况照片的类型标识。
- 不提供搜索、按日期筛选、按文件名筛选或按媒体类型筛选。
- 媒体详情支持照片全屏、GIF 动态、视频在线播放和实况照片平台展示。
- 私人媒体详情提供：
  - 下载原文件并保存到系统相册；
  - 共享到家庭相册，已共享时改为取消家庭共享；
  - 移入回收站；
  - 展开或收起操作栏。
- 下载展示进度；保存成功显示成功反馈；网络、权限或存储失败时可重试或取消。
- 共享成功后显示明确成功状态。

## 12. 家庭相册

- 家庭相册作为首页“共享”Tab 的内容展示，不占用底部主导航，不再显示内部过滤 Tab。
- 只展示当前仍处于共享状态且未进入回收站的媒体。
- 时间线默认按媒体拍摄时间从新到旧展示，并按“今天、昨天或日期”分组。
- “我分享的”从个人中心进入独立列表，只展示当前成员仍处于共享状态的媒体。
- 列表展示共享者昵称和头像，不展示完整手机号。
- 支持全屏查看照片、动态展示 GIF、在线播放视频和平台允许的实况照片展示。
- 家庭相册详情不提供下载、保存、导出、系统分享或二次分享入口。
- 媒体所有者取消共享后，媒体立即从后续家庭列表和授权中消失，但仍保留在所有者私人空间。

## 13. 删除、回收站与恢复

- 私人媒体移入回收站前必须确认。
- 确认文案必须说明：媒体将从私人空间和家庭相册隐藏，但不会删除设备本地媒体。
- 回收站只展示当前用户自己的已删除媒体。
- 列表显示进入回收站后的时长，不显示虚构的自动到期时间。
- 回收站内容一直保留，直到独立运维流程人工永久清理。
- App 不提供永久删除按钮，在线后端不拥有永久删除原文件的 OSS 权限。
- 恢复前展示确认；恢复后媒体回到私人空间并保持未共享。
- 需要再次出现在家庭相册时，所有者必须重新共享。

## 14. 帮助与反馈

- 个人中心提供“帮助与反馈”入口。
- MVP 提供内置常见问题和简短反馈表单。
- 反馈表单包含问题分类、文字描述和可选联系方式；不自动附带媒体、访问令牌、密钥或完整手机号。
- 提交失败时保留输入并允许重试。
- 不引入在线聊天、工单流转或远程客服系统。

## 15. MVP 明确不做

- 多家庭创建、加入和切换。
- 移动端成员管理、复杂角色配置或管理员媒体查看。
- 短信验证码、忘记密码、密码修改、手机号修改和账号注销。
- 选择特定设备相册或文件夹进行备份。
- 单条备份任务暂停、取消或忽略。
- 整个相册共享、批量共享、点赞、评论或其他社交互动。
- 私人空间和家庭相册搜索、排序设置或高级筛选。
- 家庭相册下载、保存、导出和二次分享。
- 每位成员独立存储配额和用户自行清理云端容量。
- App 自动永久删除 OSS 原文件。
- 业务本地通知和远程推送；系统强制的任务通知除外。
- 生物识别解锁、相机拍摄、录音、定位、联系人、日历和系统分享接收扩展。

## 16. MVP 验收标准

- [ ] 手机号和密码注册、人工审核、协议确认登录和会话恢复闭环可用。
- [ ] 未审核账号不能进入普通业务页面。
- [ ] 三项主导航、首页“私人 / 共享”双 Tab、个人中心入口和回收站层级与有效设计一致。
- [ ] 全新安装时自动备份默认关闭；用户开启后按默认仅 Wi-Fi 策略发现并上传媒体。
- [ ] 权限不足时统一显示授权说明页，不创建不可执行任务。
- [ ] 本地相册总览按两列相册卡片展示，单相册内使用三列媒体网格，全部设计状态可区分。
- [ ] 同账号重复扫描、上传重试和 MineG 下载回存不会产生重复云端媒体。
- [ ] 原始媒体保持产品定义的质量和动态资源组成。
- [ ] 管理后台没有媒体浏览或对象授权入口；ECS/OSS 高权限访问受到最小权限、审批和审计约束。
- [ ] 私人媒体支持查看、原文件保存、共享、取消共享和移入回收站。
- [ ] 首页共享 Tab 展示全部家庭共享媒体；个人中心“我分享的”仅展示本人共享媒体，两个入口均没有下载、保存、导出或二次分享入口。
- [ ] 删除不影响设备本地媒体；恢复后保持私有。
- [ ] App 和在线后端不具备永久删除原文件能力。
- [ ] 个人资料修改、帮助与反馈和退出登录可用。

## 17. 变更规则

- v2.1 是当前产品基线，旧版与本版冲突的结论失效。
- 任何新功能必须先进入设计并成为有效页面或现有页面的明确交互，再进入产品范围。
- 修改默认备份、媒体安全边界、私人/家庭可见性、家庭下载限制或永久删除边界时，必须同时更新产品、功能、技术和设计索引。
- 新的设计状态必须说明它是独立页面、同页状态还是弹层，避免把状态截图误解为新功能。
