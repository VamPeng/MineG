# 阶段 00 前端执行计划：管理端工程基座

## 目标与范围

建立 Vue 3 管理端壳和工程质量门槛，为阶段 01 的管理员登录与审核页面准备真实 API 接入能力。

## 实施任务

- 初始化 Vue 3、TypeScript、Vite、Vue Router 和 Element Plus，建立登录布局与受保护布局。
- 按 OpenAPI 生成或校验类型化 API Client，统一处理 RFC 9457 错误、request ID、超时和取消请求。
- 建立 Cookie 会话请求配置、CSRF 请求头插槽和 401 跳转机制；不在 Web Storage 保存 Token。
- 建立环境配置、构建产物、代码检查、单元测试和页面测试流水线。
- 定义可复用的加载、空状态、错误重试、二次确认和通知组件，但不提前实现超范围业务页面。
- 建立无障碍、键盘操作和桌面浏览器最小验证清单。

## 接口依赖与交付物

- 消费阶段 00 后端 OpenAPI、错误结构和健康状态，不复制手写 DTO。
- 输出可构建 SPA、路由骨架、API Client 生成/校验命令和开发说明。
- 与 Deployment 约定静态资源发布、API 基址和 HTTPS/Cookie 同源策略。

## 验证与完成门槛

- 本地和 CI 可完成类型检查、测试和生产构建。
- 统一错误组件能显示稳定业务信息并保留 request ID，界面不泄露堆栈或内部详情。
- 未认证访问受保护路由会进入登录壳；当前不得用模拟登录绕过会话。

## 不在本阶段

管理员真实登录、待审核列表、申请详情和任何成员/媒体/反馈管理页面。
