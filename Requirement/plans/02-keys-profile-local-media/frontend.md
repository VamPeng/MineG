# 阶段 02 前端执行计划：审核端范围冻结与兼容回归

## 目标与范围

管理端业务范围已在阶段 01 完成。本阶段仅保证 key grant 后端流程加入后，现有审核体验和会话契约不退化。

## 实施任务

- 回归管理员登录、会话恢复、待审核列表和幂等批准。
- 确认批准后列表行为仍以审核动作成功为准，不展示或操作家庭密钥 envelope。
- 若后端将账号保留为对外待审核，管理端不得据此添加新状态页面；只按已冻结审核 API 呈现结果。
- 更新生成的 API 类型，确认 `/me` 与移动端接口不会进入管理端导航或打包入口。
- 增加针对新增 OpenAPI 的编译兼容检查和权限越界负测试。

## 验证与完成门槛

- 阶段 01 全部管理端自动化测试继续通过。
- 管理员无法调用用户 key bundle、头像或家庭 key grant 接口。
- 构建产物中没有媒体预览、成员管理或密钥操作代码。

## 不在本阶段

新业务页面、key grant 控制台、用户资料编辑和头像查看。
