# 阶段 05 移动端执行计划：Android 私人媒体闭环

> 实施基线：[阶段 05 技术方案](./technical-design.md)。媒体不执行客户端应用层加密；注册资源读取与保存使用 HTTPS/TLS、短期授权和长度/SHA-256 校验，OSS 动态图片缩略图使用短期签名、响应图片类型与大小上限校验。

## 目标与范围

对应 M5。完成 F-09、F-10 及逻辑删除入口：私人网格、详情、完整性校验预览、本人原文件保存和删除确认。

## 实施任务

- 在契约登记私人查询、详情、访问、保存、下载回执、删除命令及页面/元素语义 ID。
- 在 C++ Core 实现私人媒体查询、响应解析、游标分页、排序、缓存失效和账号隔离；Android 只把领域快照转换为网格、空/加载/错误状态。
- 实现照片、GIF、视频详情与元数据；不显示 GPS，不可预览格式显示占位但保留本人保存能力。
- 按需获取短期精确对象地址，在受控临时文件中下载；注册资源验证长度与 SHA-256，OSS 动态图片缩略图验证签名、JPEG/PNG/GIF/WebP/BMP 响应和 5 MiB 上限；失败不展示、不播放且不输出部分文件。
- 使用 MediaStore 写回原始资源，系统确认后生成下载回执；回执存在不重复保存，缺失允许再次保存。
- 实现无前置确认的共享按钮占位不得出现；本阶段只实现删除二次确认和真实逻辑删除结果。
- 删除成功后从私人列表移除但不删除设备本地媒体，并清理当前缓存的可发现入口。
- API/RPC 路径、短期授权续签、下载校验、删除结果合并和回执状态均由 Core 编排，Transport/File/SystemAlbum Port 只执行原语。

## 测试重点

- 列表分页、缩略图损坏、视频中断、地址过期续签、重复保存、空间不足、权限撤销和删除并发。
- 其他账号数据不得因本地缓存/账号切换出现；退出时从内存清理签名地址、临时句柄和当前账号快照。
- 验证 1 GiB 资源不产生长期第二份明文，保存结果保持原质量和资源组成。

## 完成门槛

- Android 可用真实后端浏览、预览、保存并删除本人媒体，所有设计状态由真实数据驱动。
- 家庭媒体尚无保存/导出入口，私人授权用途不能被复用为家庭访问。
- F-09/F-10 及删除操作契约测试通过并转为 `FROZEN`。
- Android 生产代码不包含私人媒体业务 DTO 解析、领域列表缓存或通过 ViewModel 直接删除列表项的实现。
