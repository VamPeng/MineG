# 阶段 05 前端执行计划：私人媒体权限隔离回归

## 目标与范围

管理端保持冻结，重点证明私人访问与删除能力没有泄漏到管理员会话或管理端构建物。

## 实施任务

- 回归管理员核心流程及 OpenAPI 类型兼容。
- 添加权限负测试：管理员 Session 对私人列表、详情、访问授权和删除接口均被拒绝。
- 检查网络错误展示不回显对象签名地址、envelope、媒体 ID 组合或内部授权原因。
- 检查路由、菜单、静态资源和 source map 发布策略，不包含媒体浏览/删除调试入口。

## 验证与完成门槛

- 阶段 01 管理端测试继续通过。
- 使用真实管理员会话无法枚举、预览、保存或删除任何用户媒体。
- 管理端没有因后端 DTO 扩展而引入媒体对象类型的可见界面。

## 不在本阶段

私人媒体管理、回收站管理和任何替用户执行删除的功能。
