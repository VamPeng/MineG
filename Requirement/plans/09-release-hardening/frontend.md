# 阶段 09 前端执行计划：管理端发布加固

## 目标与范围

将阶段 01 的管理端业务范围加固为生产候选，完成安全、兼容、性能、部署和回滚验证。

## 实施任务

- 执行登录、恢复、列表、详情、批准、退出的功能、视觉、无障碍和端到端回归。
- 验证 Session ID 登录后轮换、Secure/HttpOnly/SameSite Cookie、CSRF、Origin、30 分钟闲置和 8 小时绝对过期。
- 检查 CSP、安全响应头、依赖漏洞、source map、缓存策略、API 基址和生产环境变量。
- 在待审核高水位和后端故障下注入超时、401、403、429、5xx，确认错误可理解、可重试且保留 request ID。
- 优化首屏和列表性能，验证当前支持桌面浏览器、键盘导航和二次确认焦点管理。
- 与 Deployment 固化静态资源发布、版本回滚、缓存失效和后端兼容顺序。
- 生成管理员最小使用说明和故障排查说明，不包含内部密钥或用户隐私数据。

## 发布门槛

- A1～A3 自动化、截图/语义、权限负测试和真实审核烟测全部通过。
- 构建产物只有登录与审核范围，无 Token 存储、媒体/反馈/清理入口或敏感 source map。
- 前后端滚动发布任一顺序在兼容窗口内可用，旧前端可安全处理新错误码。
- 所有发布阻断缺陷关闭并记录支持浏览器基线。
