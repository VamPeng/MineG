# 阶段 09 后端执行计划：发布加固与故障演练

## 目标与范围

形成可发布、可回滚、可观测的后端与受限运维工具版本；不在发布阶段增加业务功能。

## 实施任务

- 完成全模块单元、Repository 集成、HTTP 契约、migration、并发、幂等、权限和端到端回归。
- 执行 Token 重放、CSRF、越权、密文篡改、块重排/截断、envelope 错配、签名地址过期和日志敏感数据扫描。
- 以真实数据量验证列表索引、连接池、上传会话、1 GiB 视频、多分片和并发三端负载；固化 SLO/告警阈值。
- 与 Deployment 落实镜像锁定、配置/密钥注入、发布前备份、独立 migration、滚动发布和回滚步骤。
- 演练 PostgreSQL 备份恢复、OSS 对象恢复、STS/OSS 故障、数据库不可用、容量不足、会话异常和 key grant 积压。
- 验证 OSS 生命周期只清理过期未完成分片/临时密文；人工清理 CLI 清单、确认、独立权限和审计可用。
- 生成发布说明、迁移说明、运行手册、故障手册和已知限制。

## 发布门槛

- 空库与上一候选版本升级/回滚演练通过，不依赖服务启动自动执行不可逆 migration。
- 在线后端身份确认没有 OSS 永久删除权限；管理端和后端均无法解密媒体。
- 关键告警可触发、可归因且不泄露敏感数据，备份恢复结果经过校验。
- 所有 P0/P1 缺陷关闭，遗留项有明确风险、负责人和非发布阻断结论。

## 不在本阶段

微服务、Redis、队列、Kubernetes、CDN、管理统计或其他 MVP 外能力。
