# 阶段 09 移动端执行计划：三端发布候选与质量门槛

## 目标与范围

对 Android、iOS、HarmonyOS 和 C++ 共享核心进行全量发布加固，形成三端一致、可恢复且符合隐私边界的候选版本。

## 实施任务

- 运行三端 F-01～F-14 契约、C ABI、加密向量、状态机、UI 语义、截图和端到端全量测试。
- 覆盖注册审核、会话恢复、10 万条索引、1 GiB 视频、断点续传、分享/取消、删除/恢复、保存回执和退出。
- 注入权限撤销、弱网/断网、切网、进程强杀、设备重启、低存储、STS/会话过期、OSS/服务不可用和密文损坏。
- 扫描日志、SQLite、崩溃报告、缓存、截图与备份，确保无 Token、密钥、对象签名地址和不必要媒体明文。
- 验证三端最低系统版本、前后台生命周期、安装升级、本地 migration、账号退出和账号数据隔离。
- 执行数据主权门禁：扫描三端业务 API/RPC 路径、领域 DTO 解析、业务偏好缓存和平台端领域状态迁移；验证 PlatformPort 只执行 Core Effect。
- 复核家庭详情无保存/导出/二次分享，回收站恢复保持私有，App 无永久删除能力。
- 固化构建签名、版本号、环境切换、灰度/回滚、隐私说明、已知平台降级和支持手册。

## 发布门槛

- 三端产品 MVP 验收项全部通过，公共契约无未解释差异，Android 参考行为未被破坏。
- 性能达到：10 万索引不全量载入内存，1 GiB 视频可暂停续传且无第二份长期明文。
- 升级和回滚不会破坏 SQLite、密钥包、上传任务或下载回执；失败可安全恢复。
- 所有 P0/P1 缺陷关闭，平台限制和非阻断缺陷有记录、负责人及后续处理计划。
- Android 数据层迁移清单全部关闭；iOS/HarmonyOS 未复制任何过渡 Android 业务数据实现。

## 最终交付物

三端候选包、C++ 核心版本、契约与测试报告、发布检查表、隐私安全报告、性能报告和已知限制清单。
