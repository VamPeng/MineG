# 阶段 04 前端执行计划：队列扩容兼容回归

> 统一负载模型、权限边界和退出标准见[阶段 04 技术方案](./technical-design.md)。

## 目标与范围

管理端继续保持范围冻结，确保上传负载与观测中间件变化不会影响审核端可用性或授权边界。

## 实施任务

- 在服务端批量上传压测期间执行登录、列表、批准流程的延迟与错误回归。
- 验证统一限流不会让管理员与移动上传错误地共享同一额度或错误提示。
- 更新 API 类型并继续只暴露 admin 路由；私人列表和上传状态不得进入管理 UI。
- 检查前端日志与错误上报只携带 request ID，不记录 Cookie、CSRF 值或服务端内部错误。
- 增加负向契约测试：管理员 Cookie 调用上传/私人媒体接口、移动 Bearer 调用管理员接口均被拒绝。

## 验证与完成门槛

- 两设备各最多 4 个并发对象传输的参考负载持续 10 分钟时，管理端核心流程无 5xx；请求 p95 不超过空载基线 2 倍且不超过 750 ms。
- 管理员调用上传/私人媒体接口仍为拒绝，路由和菜单无新增项。
- 阶段 01 自动化测试持续通过。

## 不在本阶段

上传任务监控、配额面板、用户相册和运维指标页面。
