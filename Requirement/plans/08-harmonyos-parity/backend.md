# 阶段 08 后端执行计划：HarmonyOS 接入观测与三端收敛

## 目标与范围

继续 B7 加固，保证 HarmonyOS 使用同一业务 API 和安全边界，并将三端运行数据收敛为发布前基线。

## 实施任务

- 使用 HarmonyOS 客户端运行 F-01～F-14 契约和端到端测试，不创建 HarmonyOS 专用 endpoint。
- 验证 PhotoAccessHelper 资源、动态照片、后台任务和 Node-API 生命周期造成的重试/取消模式。
- 完善三端维度的会话、key grant、上传、访问、分享和恢复指标，统一错误分类。
- 对高频重试、长时间暂停、时钟偏差和网络切换执行幂等、签名有效期与状态收敛测试。
- 只做向后兼容修复；冻结契约变化必须同时回归 Android/iOS 并记录技术决定。
- 固化阶段 09 使用的容量、失败率和告警阈值候选。

## 完成门槛

- Android、iOS、HarmonyOS 对相同 API、密文格式和业务状态结果一致。
- HarmonyOS 重启/后台恢复不产生重复媒体、错误完成或越权访问。
- 三端关键指标和错误可比较，服务日志无平台敏感信息或密钥材料。

## 不在本阶段

HarmonyOS 专用业务分支、放宽对象授权或服务端媒体兼容转换。
