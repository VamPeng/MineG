# 阶段 08 前端执行计划：HarmonyOS 阶段管理端回归

## 目标与范围

管理端保持冻结，验证 HarmonyOS 注册申请可通过同一审核链路处理，且三端收敛改动不影响 Web 安全与交互。

## 实施任务

- 使用 HarmonyOS 注册申请执行一次真实登录—列表—详情—批准流程。
- 对后端兼容修复持续执行 API 类型、Session、CSRF、401、幂等确认和权限负测试。
- 执行阶段 06 的页面截图/语义基线，确认无平台特定文案或操作。
- 复核构建依赖、source map、环境变量和错误上报，为阶段 09 发布准备输入。

## 完成门槛

- 三个平台的注册申请由同一管理端无差别审核。
- A1～A3 全套功能、安全和视觉回归通过。
- 管理端范围仍严格限制为登录与审核。

## 不在本阶段

平台筛选、设备列表、三端统计或平台特定审批规则。
