# 阶段 03 前端执行计划：上传能力隔离回归

## 目标与范围

管理端保持阶段 01 范围，验证新增媒体与上传 API 不会扩大管理员权限或影响审核流程。

## 实施任务

- 更新并编译检查 OpenAPI Client，管理端仅导入 admin 分组；媒体、上传、STS 类型不得形成页面入口。
- 回归登录、列表、详情和批准流程，确认新增 API 中间件不会改变 Cookie、CSRF、错误格式或 request ID。
- 增加权限负测试：管理员 Session 调用用户上传、媒体或对象授权接口必须被拒绝。
- 检查构建产物与路由表，不包含 OSS 凭据、媒体对象地址或调试浏览入口。

## 验证与完成门槛

- 阶段 01 管理端测试和真实审核烟测全部通过。
- 安全测试证明管理员不能取得 STS、媒体清单、密钥 envelope 或密文访问地址。
- 无新增业务页面和菜单。

## 不在本阶段

上传监控页面、媒体审核、对象存储浏览器和用户媒体排障工具。
