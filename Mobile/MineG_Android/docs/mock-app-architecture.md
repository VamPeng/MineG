# MineG Android Mock 页面架构

本阶段以产品需求 v2.0 和 Stitch 有效页面索引为基线，在后端接口尚未完整可用时，用 Android 内存 Mock 数据先验证完整页面结构、导航层级和状态语义。

Debug 验收包默认视为“登录、审核和授权均已完成”，启动后直接进入带默认内容的 `PrivateSpace`。页面右侧的“调试”悬浮按钮仅在 Debug 包出现，可快速切换页面和视觉状态；Release 包不会包含可见调试入口。

## 1. 路由图

### 账号与首次进入

| 路由 | 页面 | 进入条件 |
|---|---|---|
| `Login` | 登录 | 无有效会话或主动退出 |
| `SignUp` | 注册 | 从登录页进入 |
| `ReviewPending` | 审核等待 | 注册成功但管理员尚未审核通过 |
| `Legal(document)` | 服务协议 / 隐私政策 | 登录页打开，返回登录页 |
| `Permission` | 统一相册授权说明 | 已审核成员首次进入或权限不足 |

### 三项主导航

| 路由 | 页面 | 底部导航 |
|---|---|---|
| `PrivateSpace` | 首页；顶部“私人 / 共享”切换私人网格与家庭共享时间线 | 锁 |
| `Backup` | 本地相册与备份状态 | 云上传 |
| `Profile` | 我的 | 人物 |

主导航切换会清空次级页面返回栈，避免从另一个 Tab 返回到旧详情页。

### 次级页面

| 路由 | 父级 |
|---|---|
| `PrivateMediaDetail(mediaId)` | 私人空间 |
| `SharedMediaDetail(mediaId)` | 首页共享 Tab 或我分享的 |
| `SharedByMe` | 我的 |
| `LocalAlbum(albumId)` | 备份 |
| `BackupSettings` | 备份或我的 |
| `ProfileEdit` | 我的 |
| `RecycleBin` | 我的 |
| `HelpFeedback` | 我的 |

移入回收站确认、恢复确认和退出登录确认属于页面弹窗状态，不进入路由返回栈。

## 2. 页面状态

### 通用加载状态

`PageLoadState` 统一定义 `LOADING / CONTENT / EMPTY / ERROR`，用于私人空间、家庭相册和回收站。错误和空状态不会创建独立路由。

### 备份状态

`BackupStatus` 覆盖有效设计中的：

- 需要权限；
- 扫描中；
- 上传中；
- 等待 Wi-Fi；
- 网络离线；
- 设备空间不足；
- 服务空间不足；
- 服务不可用；
- 同步完成；
- 自动备份关闭。

登录失效不属于备份页面状态，后续真实会话层应直接清理会话并导航到 `Login`。

### 私人媒体操作状态

`MediaActionState` 覆盖空闲、下载中、保存成功、保存失败和共享反馈。删除确认由 `AppDialog.DeleteMedia` 表达。共享媒体详情不包含保存、导出或二次分享状态。

### 表单状态

登录、注册、资料编辑和帮助反馈均保留输入值、字段错误、加载状态与提交结果。正式 Repository 接入失败时，应更新同一页面状态并保留输入，不跳转到独立错误页。

## 3. Mock 数据与真实接口替换

- `MockMineGRepository` 只负责提供确定性的成员、媒体、本地相册和回收站示例。
- `MineGAppViewModel` 持有唯一 `StateFlow<MineGAppState>`，页面只渲染状态并发送用户意图。
- `AppRoute`、页面状态和 UI 数据模型不依赖 HTTP DTO、数据库实体或 Android `MediaStore` 类型。
- 后续真实功能接入时，用 Repository/UseCase 替换 Mock 行为；路由和页面状态保持稳定。
- 现有账号、加密、MediaStore 和单媒体备份实现暂时保留，后续按功能域逐步适配到这套页面状态，而不是让页面直接调用传输层。

## 4. 页面验收方法

1. 启动 Debug App，直接验收首页私人内容、顶部“私人 / 共享”切换和三项底部导航。
2. 点击右侧“调试”按钮，通过“主页面”或“次级页面”快速跳转。
3. 在首页私人内容、共享内容、“我分享的”和回收站中切换“默认内容 / 加载中 / 空状态 / 加载失败”。
4. 在备份页切换权限、扫描、上传、网络、空间、服务、完成和关闭等全部状态。
5. 在私人媒体详情中切换下载中、保存成功、保存失败和共享反馈。
6. 点击“恢复默认验收首页”，清除本轮内存操作并回到默认私人空间。
