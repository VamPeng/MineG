# 服务器准备检查

## 已验证项目

- Ubuntu 24.04，x86_64
- Docker 与 Docker Compose 可用
- Git 可用
- 根文件系统容量、内存和 Swap 已检查
- 部署前未发现占用 Web 服务端口的既有应用

精确容量、主机名、实例 ID、登录用户名和网络地址不写入本仓库。

## 可重复执行的检查

运行：

```bash
./scripts/check-server.sh
```

该脚本只读取系统信息，不安装软件、不修改防火墙，也不启动或停止服务。

## 部署前仍需确认

- 应用代码来源与可信提交版本
- 容器的内存限制
- 数据库持久化目录
- 安全组中需要开放的最小端口
- 域名解析和 TLS 证书方案
- 日志轮转、备份和恢复演练

在反向代理和 TLS 准备完成前，不应直接把数据库或内部应用端口暴露到公网。
